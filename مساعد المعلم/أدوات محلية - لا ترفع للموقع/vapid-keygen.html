🔑 توليد مفاتيح VAPID لإشعارات «مساعد المعلم»

تُولَّد المفاتيح داخل متصفحك فقط ولا تُرسل لأي مكان. لا ترفع هذا الملف إلى الموقع، ولا تحفظ المفتاح الخاص في أي ملف أو رسالة. بعد نسخه إلى Cloudflare أغلق الصفحة.
  1. Cloudflare ← Workers ← homework ← Settings ← Variables and Secrets ← Add
  2. VAPID_PUBLIC_KEY نوع Text ← الصق المفتاح العام
  3. VAPID_PRIVATE_KEY نوع Secret ← الصق المفتاح الخاص
  4. VAPID_SUBJECT نوع Secret ← mailto:بريدك@example.com
  5. Deploy، ثم افتح /version وتأكد من "push": true

تغيير المفاتيح لاحقًا يُبطل اشتراكات الأجهزة، فتحتاج إعادة تفعيل الإشعارات على كل جهاز.
