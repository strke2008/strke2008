# اختبار الدخان — مساعد المعلم

يفتح اللوحة والبوابات في متصفح آلي ببيانات تجريبية ثابتة، ويضغط كل زر في كل تبويب،
ويُبلغ عن أي خطأ JavaScript أو رقم غير منطقي. **لا يتصل بخادمك الحقيقي**: كل طلبات
`workers.dev` تُجاب من خادم وهمي داخل الاختبار.

## التشغيل
```bash
cd tests
npm install            # مرة واحدة (يثبت Playwright)
npx playwright install chromium   # مرة واحدة إن لم يكن Chromium مثبتًا
npm test               # الفحص الكامل (~دقيقة)
npm run test:quick     # بدون الضغط على كل زر (~30 ثانية)
npm run shots          # مثل test مع لقطات شاشة لكل تبويب في tests/shots/
```
النتيجة: `✓ كل الفحوص نجحت` أو قائمة بالمشاكل ومكانها. شغّله بعد أي تعديل قبل الرفع.

## ما يفحصه
1. صياغة كل سكربت في كل صفحة وكل ملف JS.
2. كل دالة في `onclick` وأخواتها معرّفة.
3. لا معرّفات `id` مكررة.
4. كل تبويب (حاسب وجوال) وكل تقرير فرعي والنوافذ الرئيسية تفتح بلا أخطاء، ولوحة واحدة فقط ظاهرة.
5. الضغط على كل زر ظاهر (عدا الحذف والمسح والاستيراد).
6. متوسط الدرجات نسبة صحيحة، ولا عداد «سلّم X من Y» فيه X أكبر من Y.
7. بوابة الطالب وبوابة المعلم والمختبر تفتح بلا أخطاء.
