# مساعد المعلم

| المجلد | ما هو | أين يُنشر |
|---|---|---|
| `teacher-dashboard/` | لوحة تحكم المعلم (PWA) | Cloudflare Pages |
| `teacher-portal/` | بوابة المعلم (الجدول وتنبيهات الحصص) | Cloudflare Pages |
| `student-portal/` | بوابة الطالب + `lab/` المختبر الافتراضي | Cloudflare Pages |
| `worker.js` | الخادم (Cloudflare Worker + KV) | Cloudflare Workers |
| `madrasati-bridge/` | إضافة Chrome/Edge لسحب الواجبات من مدرستي | تثبيت محلي (انظر README داخلها) |
| `tests/` | الاختبار الآلي (لا يُنشر) | — |
| `tools/` | أدوات صيانة (لا تُنشر) | — |
| `أدوات محلية - لا ترفع للموقع/` | أدوات تُفتح على جهازك فقط | — |

## بنية لوحة التحكم
```
teacher-dashboard/
  index.html      الهيكل فقط (الأزرار والأقسام)
  css/NN-*.css    التنسيقات — بنفس ترتيب ظهورها الأصلي (الترتيب مهم)
  js/NN-*.js      السكربتات — كل ملف مستقل، وتُحمَّل بالترتيب
  sw.js, manifest.webmanifest, pwa/
```
**ارفع المجلد كاملًا** عند النشر، لا `index.html` وحده.

كل رابط في `index.html` يحمل `?v=...` (بصمة المحتوى) حتى لا يبقى المتصفح على نسخة قديمة.
بعد تعديل أي ملف في `css/` أو `js/` شغّل:
```bash
python3 tools/bump-versions.py
```

## ترتيب النشر عند التحديث
1. **الخادم أولًا** (`worker.js`) ثم الواجهات. الواجهات الجديدة تعمل مع الخادم القديم أيضًا
   (ترويسة كلمة السر لا تُستخدم إلا بعد أن يؤكد الخادم دعمها)، لكن الخادم أولًا هو الأسلم دائمًا.
2. إضافة مدرستي: بعد تحديث ملفاتها افتح `chrome://extensions` واضغط ↻ على الإضافة.

## قبل كل نشر
```bash
cd tests && npm install   # مرة واحدة
npm test                  # يجب أن ينتهي بـ ✓ كل الفحوص نجحت
```
